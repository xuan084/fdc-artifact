## 2. go 判据逐条判定（v9_plan §2，dev 950–999）

1. FDC-HG/FDC-BF 的 UB95 需要在一个数据集上 < 0.90、另一个上 ≤ 1.00。实际 CR9 为 0.990，X5（ε = 0.02）为 0.992，两个都没有低于 0.90。**未满足。**
2. toy 与 dev 均 0 错误流，且单测证明 Λ̄ ≥ 精确 MGF。dev 和 toy 都是 0 错误流；单测用随机盒子检验了包络对盒内每个 M 都不低于精确 MGF，参照是长双精度全支撑和 mpmath 预言机。**满足。**
3. 每检查点耗时 ≤ 10 s。实测最大 7.14 s。**满足。**

**裁决：NO-GO。** 按 §2 的预案，FDC-BF 保留为主方法，FDC-HG 作为描述性消融写进论文，表述为"精确 HG 包络在 dev 上带来 3–6% 的提速，有效性不变"。它不进入 lock v9 的确认性比较。

## 3. 为什么增益小（诊断）

计划预期 CR9 上约 0.8，依据是低基率时 Bennett 最松。实际只有 0.97，原因是认证发生时各单元已经处在高斯区间：

- CR9 在 N80 附近 n_c 约 10⁴–10⁵，最优 λ 下 |u|/n ≪ 1。此时 Bennett-FPC 的 φ(x) ≈ x²/2，而精确 HG 的对数 MGF ≈ u²Var/2，两者只在三阶及以上项上不同。
- 方差上确界由同一个盒子决定，在 clip(1/2) 处取到，HG 包络与 Bennett 一样。
- 低基率单元的偏度确实让左尾更紧，但这些单元在方向方差中占比小。CR9 的方差集中在 m ≈ 0.03–0.3 的段 2、6、8。

随机单元测试中，包络与 Bennett 的中位比约为 0.72，那是在 Λ ∈ [0.5, 40]、包括小 n 的情形下测得的。在决定 N80 的检查点上这一差距已经被压缩，宽度只改进约 1–4.5%（见 x12 比）。CR9 的检查点网格较粗，公比约 1.30，因此 N80_pen 只在 12% 的流上提前了一格。

## 4. 对论文与 v9 的含义

- 主方法仍为 FDC-BF。FDC-HG 作为一行描述性消融，说明"把单元不等式换成精确有限总体 MGF 包络，速度几乎不变"，从而支持论文的主张：几何（方向级联合证书）才是主要来源，单元不等式不是。dev 中 FDC-BF/RECT-ck-HG 为 0.65 和 0.34，FDC-HG 在此基础上只多出约 3%。
- 不需要为 FDC-HG 起草 lock v9 块，块 A / B 的主比较仍是 FDC-BF 对最强矩形。
- 有一个副产品值得记录：scipy 的 `hypergeom.logpmf` 在 N ≈ 2.7·10⁶ 时有约 2e-9 的偏差（external reviewer r1 的反例）。FDC-BF 和 RECT-ck-HG 的盒子用的是 scipy 的尾概率 sf / cdf，是否受类似数值误差影响本任务没有核查，建议另行核查（误差量级远小于 α_side）。
