## 2. FDC 方法规格（唯一版本，锁前冻结）

### 2.1 组件
1. **冻结读表**：每段对照 / 处理各 0.5（数据无关规则）。某段对照池耗尽后，该段到达全部转处理臂（`StreamEngine._resel` 按 p 在剩余臂上重新归一化，对 50/50 就是全转）。两段都耗尽的到达跳过，但照样计费。整个日程只由置换种子和标签生成，与结果无关。**两阶段版本删除**，0.40 / 0.45 份额只作为探索性记录写进决策日志。
2. **证书**：直接复用 r4 的 `certify/quadknap.qfc_certificate_enum`，即 Lemma L1 的方向级 Bernstein 宽度 √(2βV̄) + bβ/3。方差上界用 r4 已证明的 **Lemma L2 反演型 UCB**（`make_stats`，`theory_checks.mc_l1.bernstein_mu_ci` + `sigma2_ucb`），**不用** contrarian 离线脚本里的每检查点经验 Bernstein 公式。耗尽单元精确，从 V 与 b 中删去。只要 π̂ 或挑战者触及 n = 0 的单元，宽度就记为 +∞。
3. **中心与停止**：π̂_q 是 Ĵ 在 Π_{B_q} 上的 argmax，并列时取最小枚举序号。U_q = max_{π′∈Π_{B_q}} [Δ̂(π′, π̂_q) + width(π′, π̂_q)]，U_q ≤ ε 即认证，答案在首次认证后冻结。流在首个"已认证 ≥ 12 题"的检查点停止。

### 2.2 δ 账本（全部由代码根据 ctx 自动计算，禁止配置覆盖）

| 事件 | 计数 | 指数 | 预算 |
|---|---|---|---|
| E_main：对每个 (q, π′ ∈ Π_{B_q}, k) 的方向事件（单侧） | Σ_q |Π_{B_q}| · K = 3386 · 20 | β = ln(3386·20/0.045) = **14.2242** | δ_main = 0.045 |
| E_var：每个单元 × 检查点 × 双尾 | 2 · S·A · K = 2·18·20 | x_v = ln(720/0.005) = **11.8776** | δ_var = 0.005 |
| 合计 | | | **δ = 0.05** |

- 该 δ 拆分（0.045 / 0.005）在开发结果出来之前就已写进提案和离线代码的默认值，此后不搜索、不调整。C_var 从 r4 的 48（为 S = 16 预留）改为实际单元数 18，这是合法收紧，记入决策日志。
- `FDCMethod` 的 `setup()` 根据 ctx 计算 Σ_q|Π_{B_q}|、K、S·A，再得出 β 与 x_v。构造函数不接受 β、x_v、份额这类覆盖参数。凡是参数被覆盖的实例（例如消融或探索），一律标记为 `validity="none"` 并改名（单测守卫）。这样 β = 14.1 这种硬编码就不可能再被计入严格结果（external reviewer P0-1）。
- **β = 14.1 的旧结果**（0.856 等）全部降级为探索性记录。按并集论证，它只能给出 0.05595 > δ 的保证。

### 2.3 概率空间（写进定理）
- 记 𝒜 为完整预生成的日程：段到达序列、计划臂、重选用均匀数。它只由置换种子和标签决定，与池内记录的置换独立。所有陈述都条件于 𝒜。𝒜 不包含任何结果信息，也不是停止后截断的路径（external reviewer P0-2(1)）。
- 50/50 冻结时，各检查点的计数 n_c(k) 是 𝒜 的函数。条件于 𝒜，各单元是相互独立的不放回样本，所以 Lemma L1 成立：Hoeffding 凸序，加上 Bernstein MGF。
- 停止只在 K 个固定检查点上发生。两个检查点之间不发证书（external reviewer P0-2(2)）。
- π*_q 是固定未知量：有限总体、权重、成本、可行类都固定，并列按确定性规则打破，且这些对象都不依赖认证数据（ε、类、权重已在 r4 锁定）。同时事件为 E = ∩_{q,k,π∈Π_{B_q}} {J(π*_q) − J(π) ≤ Ĵ_k(π*_q) − Ĵ_k(π) + w_k(π*_q, π)}，它覆盖任意数据依赖的 π̂_q(k)。证书对**全部可行挑战者**取最大值，π*_q 也在其中，不做任何按数据剪枝。
- 方差上界是随机的，处理方式是取交集：在 E_var 上 σ_c² ≤ σ̄_c²(k)，宽度对 V 单调，所以 E_main（以真方差表述）∩ E_var 推出所需不等式。绝不把随机方差当成已知方差直接代入 MGF（external reviewer P0-2(3)）。

### 2.4 定理 FDC-1（由 `r5_fdc_spec_theory` 写出完整证明）
条件于 𝒜，P(∃k ≤ K, ∃q：U_q(k) ≤ ε 且 J(π*_q) − J(π̂_q(k)) > ε | 𝒜) ≤ δ_main + δ_var = 0.05。
推论：流级 FWER ≤ δ，这一结论对"停在 12/15"和"运行到 τ_R 认证全部 15 题"两种观察窗口都成立。
边界情形必须逐条覆盖：n = 0、μ̂ ∈ {0, 1}（全零或全一）、池耗尽、单段两臂都耗尽、π̂ 与 π′ 只在耗尽单元上不同（此时宽度为 0、差值精确）。

## 5. 终点与统计分析规格（交付物 4）

### 5.1 终点（逐流）
- **N80_pen（主终点）**：设 k* 为首个已认证 ≥ 12 题的检查点。若 k* 存在且此前所有证书都正确，N80_pen = t_{k*}；若此前任一证书错误，N80_pen = τ_R；若始终凑不满 12 题，N80_pen = τ_R。恰好在最后一个检查点 t_K = τ_R 凑满的情况，数值上等于 τ_R，但另记 `completed = true`。
- 同时报告：原始停止时刻 N80_raw（不做错误惩罚）、`completed`、`fwer_event`、`censored = (未完成 ∨ 有错)`、逐题认证时刻、N100（15/15 的完成时刻，单独跑全视界）、逐预算完成曲线、格点差的分布与并列比例。

### 5.2 比较
- **配对单位**：同一置换种子的流。对每个 r ∈ 𝓡 计算 d_i = log N80_pen(FDC, i) − log N80_pen(r, i)。点估计为 exp(mean d)。CI 用配对 bootstrap（B = 10⁴，种子 42，按流重抽样），C1 用**单侧 95% 上界**。
- **C1 = 交并检验（IUT）**：对 𝓡 中所有对手，每个上界都 < 1.0。IUT 只对合取结论负责，不需要多重性校正。如果论文要同时发布逐对手区间并逐一解读，则改用 Holm 校正的单侧上界（α = 0.05 / |𝓡| 逐级），并在 lock 中写明。
- **措辞门槛（冻结）**：点估计 ≤ 0.90 且上界 < 1.0 时，才能对该对手写 "faster by ≥10%"；只有上界 < 1.0 时，只写 "faster"。提案中"点估计 ≤ 0.90 是否保留"的悬置问题，到此关闭。
- **C2**：错误流的单侧 CP 上界 ≤ δ（200 流时至多 4 条，CP(4, 200) = 0.0452，CP(5, 200) = 0.0518；400 流时至多 12 条）。CP 不过只表示"实证安全验收未通过"，不等于定理被证伪（external reviewer P1-4）。流间变异描述的是固定日志上的回放随机性，不是独立数据集。
- **E-cost**：对 {B2-fav-tight, FIX-bal-fav, Peace-fav-bal, B2-fav, Peace-fav}，用同样的配对比报告双侧 95% CI，不设通过线。"最快 plug-in"指评价块总体几何均值最小的那个固定方法，不逐流挑选。
- **检查点敏感性**：主网格 K = 20。敏感性分析用 K = 60（共同更密网格），所有方法都在 K = 60 下重算各自的时间并集预算（FDC 的 β 增加 ln 3），只报告，不作门。K = 60 与 K = 20 的数字不混合引用。

### 5.3 功效与流数
开发 T2 给出每个对手的 log 比标准差 σ̂_r 与点估计 θ̂_r。`r5_gate_decision` 对 C1 中最难的对手（上界最接近 1 的那个）做蒙特卡洛功效计算（10³ 次复制）。若 N = 200 时 IUT 功效 ≥ 0.8，评价用 200 流；否则启用扩展块 30200–30399，总计 400 流。规则在 lock v5 中冻结，评价开始后不得改动。

### 6.3 C4 析因（机制）

8 个格子都是严格方法。按 log N80_pen 估计主效应与交互，并做 Shapley 分解；有交互就如实报告，不强行写成三个独立因子的乘积（external reviewer P0-4）。另一个对照用来隔离"冻结设计允许方向级证书"这一能力：设计相同时，比较 FDC 与 B4-bal（矩形）。

## 10. 风险（meta-reviewer 自检）
1. **新颖性约 3/10**：组件都有先例，贡献要落在"冻结设计换来方向级证书的合法性"、组合预算前沿上的单一 δ、真实日志不放回回放，以及公开基准上。即使 C1 显著，这一项也决定能否过 WWW 主会。
2. **严格对手偏弱**：严格对手都是矩形证书。原因是在不放回 + 自适应条件下，方向级证书没有已发表的严格版本，这一点本身就是论文要讲清的事实，而不是我们挑选对手的结果。Hait-SW 和 Molitor-WoR 用来回应"稻草人"质疑。
3. **0.40 份额可能比 0.50 快**：FDC 锁 0.50，T2 有可能比 0.856 慢。这是为了避免 forking path 付出的代价，如实承受。
4. **计时在并发环境下测得**，偏高；墙钟结论需注明这一点。
5. **概率估计**：external reviewer 估计录用概率约 7%（3–12%）。本计划修复的是可检验性，提高不了新颖性。
