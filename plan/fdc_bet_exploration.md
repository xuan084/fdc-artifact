## 1. 问题与目标

v6 dev 块（种子 950–999，CR9，ε=0.001）显示：在同一冻结 50/50 日程下，FDC 的联合方向级 Bernstein 证书相对单元级 Bernstein 矩形快约 2.5 倍（几何收益），但单元级精确超几何检查点矩形 RECT-ck-HG 和对冲资本 WoR 下注矩形 HC-WoR 的单元区间比 Bernstein 紧得多，于是 FDC/HG = 0.804（UB 0.838），FDC/HC = 0.821（UB 0.860）。

目标：在保持 FDC 的设计（冻结 50/50，日程摘要逐位相同）、联合几何、检查点保证（K = 20，FWER ≤ δ = 0.05）的前提下，把紧的有限总体不等式放进方向级证书，使 dev 上 FDC-bet / 最强同强度矩形的 UB95 < 0.70。

## 2. 理论

### 2.1 设定（沿用 fdc_theorem §2）

条件于无结局的完整日程 𝒜，各单元 c = (s, a) 的前 n_c(k) 次抽取是来自二值池 (N_c, M_c = N_c μ_c) 的均匀不放回样本，单元之间相互独立（Fact 0）。n_c(k)、耗尽指示、活单元集合都是 𝒜 的函数。对挑战者 π′、中心 π̂（A = 2），差异段集合 D = {s : π′(s) ≠ π̂(s)}，系数 ã_c 在挑战者单元 (s, π′(s)) 上为 −w_s，在中心单元 (s, π̂(s)) 上为 +w_s。需要控制的偏差是

  Y = Σ_c ã_c (μ̂_c − μ_c) = [Δ(π′, π̂) − Δ̂(π′, π̂)]（取 π′ = π*_q 时就是 Theorem FDC-1 的 E_main 事件）。

### 2.2 单元对数 MGF 上界（核心引理）

**引理 H（超几何 = Poisson-二项）。** X ~ Hypergeometric(N, M, n) 的 pgf 只有实零点，因此 X 与 n 个独立 Bernoulli(p_i) 之和同分布（Vatutin & Mikhailov 1982；综述见 Tang & Tang, *The Poisson Binomial Distribution — Old & New*, Statist. Sci. 2023）。由分布相等，Σ_i p_i = n m，Σ_i p_i(1 − p_i) = Var X = n m(1 − m)(N − n)/(N − 1)，其中 m = M/N。

**引理 B（Bennett-FPC）。** 对任意实数 u，

  log E exp(u(μ̂ − m)) ≤ Ψ^B(u; m) := n m(1 − m) (N − n)/(N − 1) · φ(|u|/n)，φ(x) = eˣ − 1 − x。

证明：μ̂ − m = (X − nm)/n = Σ_i (B_i − p_i)/n。对每个中心化 Bernoulli，|B_i − p_i| ≤ 1，Bennett 引理给出 log E e^{t(B_i − p_i)} ≤ p_i(1 − p_i) φ(|t|)（t ≥ 0 时用 B_i − p_i ≤ 1；t < 0 时对 −(B_i − p_i) ≤ 1 同样适用）。由独立性求和即得。∎ 这就是带**精确**有限总体方差的 Bennett 界；FDC 的 Lemma L1 用的是去掉 (N − n)/(N − 1) 因子的 Bernstein 版本（fdc_theorem §8："No finite-population correction is used anywhere"）。

**引理 K（二项 KL）。** Hoeffding（1963，Thm 4）凸序：不放回样本和 ≤_cx 有放回样本和，所以 log E exp(u(μ̂ − m)) ≤ Ψ^K(u; m) := n[log(1 − m + m e^{u/n}) − m u/n]。

两者都是合法上界，所以逐点取 Ψ = min(Ψ^B, Ψ^K) 也合法。数值核验：对 N ∈ {10, 23, 40, 101}、n 的 6 个取值、全部 M、50 个 u，精确超几何对数 MGF 与两个上界的最大差都 ≤ 1e−9（单测 `test_cell_bounds_dominate_exact_hypergeometric_mgf`）。实现中 Ψ^K 用 logaddexp 计算，避免 m = 1 时的相消误差；这个误差在首次数值检查中出现过，属于浮点问题，不是界本身的问题。

耗尽单元（n = N）是精确的，Ψ = 0；n = 0 的单元若被方向触及，宽度为 +∞。

### 2.3 方向级 Chernoff 宽度与未知 μ 的处理

对固定 𝒜、方向 ã、检查点 k，令 F(λ; μ) = Σ_c Ψ_c(λ ã_c; μ_c)，t(μ) = inf_{λ>0} (β + F(λ; μ))/λ。由 Chernoff 不等式与单元独立性，P(Y > t(μ) | 𝒜) ≤ e^{−β}（取 λ_j 使 (β + F(λ_j))/λ_j ↓ t，再对 {Y ≥ t + 1/j} 取极限）。t(μ) 是 𝒜 的确定函数，因此逐事件的并集计数与 FDC 相同。

方差事件：E_var = {μ_c ∈ B_c(k)，对所有 c, k}。B_c(k) 是精确超几何双侧检验反演区间，α_side = δ_var / (2 S A K)，并在检查点间取运行交集（同时事件上合法；与 RECT-ck-HG 同一构造）。L2 变体则沿用 FDC 的 Bernstein 反演盒，以便做消融。

在 E_var 上，对**任意**（可依赖数据的）λ̂ > 0：

  t(μ) ≤ (β + F(λ̂; μ))/λ̂ ≤ (β + Σ_c Ψ̄_c(λ̂ ã_c))/λ̂ =: w(π′, π̂)，其中 Ψ̄_c(u) = sup_{m ∈ B_c} Ψ_c(u; m)。

两个上界对 m 都是凹的：Ψ^B 是 m(1 − m) 的倍数；Ψ^K 的二阶导为 −n(e^s − 1)²/(1 − m + m e^s)² ≤ 0。所以上确界有闭式解，分别在 clip(1/2) 和 clip(m*(s)) 处取到，其中 m*(s) = (e^s − 1 − s)/(s(e^s − 1))。对 min 型，使用 min(sup Ψ^B, sup Ψ^K) ≥ sup min。实现中 λ̂ 取每对方向自己的几何网格 λ₀ · [1/200, 10]（161 点，公比约 1.069），λ₀ = √(2β / V̄_pair)。网格只影响松紧，不影响有效性。

随机的盒子与 FDC 中的 σ̄² 一样，是通过"交集 + 上确界"处理的，**从不**代入 MGF：E_main 用真实 μ 陈述，E_var 单独陈述。

**附加的免费矩形。** 在 E_var 上，单元矩形 Δ(π′, π̂) ≤ Σ_{s∈D} w_s(hi[s, π′(s)] − lo[s, π̂(s)]) 自动成立，因此逐挑战者取 min(Δ̂ + w, rect) 不消耗额外 δ（变体 `+R`）。

### 2.4 为什么不用"真正的"方向级下注鞅（候选 (a)）

FDC 只需要在 K 个预设检查点有效。在固定样本量下，常数 λ 的下注 / 指数鞅在该时点的取值正好是 Chernoff 被积式 e^{λY − F(λ)}，而 Chernoff 允许事后（数据依赖地）对 λ 取最优，下注过程只能使用可预测的 λ。因此在检查点保证下，对于同一个指数 MGF 上界，2.3 节对 λ 事后取最优的构造逐点不劣于任何固定 λ 的方向级下注过程（勘误 2026-10-04，external reviewer v7 审查：此前写成"支配任何固定 λ 的下注过程"，范围过宽；结论只限于优化同一个 MGF 界）。可预测混合（如 WSR 的 PrPl λ 序列）付出的是时间一致性的代价，而这种一致性正是 FDC 不需要的。

方向级**时间一致**版本（候选 (a) 的真正价值，可以消除 R6 的保证强度不对等）需要把各单元的 WoR 下注鞅在全局时间上相乘（日程与结局独立时，乘积是上鞅），再对方向做并集，并对 λ 做混合或拼接。这会额外付出约 log log 的代价，而且 WoR 条件均值逐步漂移，单元增量的形式也更复杂。按时间盒没有实现，见 §5 的说明。

### 2.5 方向并集的结构（候选 (b) 的扩展：FDC-MR）

A = 2 时，偏差 Y 只依赖带符号的段子集 (D, σ_D)：Y = Σ_{s∈D} σ_s w_s e_s，其中 e_s 是第 s 段的 uplift 估计误差。因此同一 (D, σ) 事件被所有问题 q 和所有诱导出它的方向对共享。FDC-MR 给每个带符号子集分配一个数据无关的权重：

  ω(D, σ) = ρ_{|D|} / (C(S, |D|) 2^{|D|})，β(D) = ln(K / (δ_main ω))，

并且可以混入 FDC 原本的 (q, π) 并集（权重 ρ_F，只用于整方向，即族 A）。在 E_main 上，所有族 B 子集事件同时成立。对 D 的任意划分 T_1 ∪ … ∪ T_r，有 Y(D) = Σ_j Y(T_j) ≤ Σ_j w(T_j)，所以证书用子集 DP 取最优划分（3^S 次运算，S = 9 时可以忽略）：

  B(D) = min(w(D), min_{T ⊊ D, T ∋ min D} B(T) + B(D∖T))，

每块还可再与免费矩形取 min。族 A 只用于整方向，因为子块对应的策略未必可行，不在族 A 的并集内。Theorem FDC-1 的证明逐字适用：π′ = π*_q 是挑战者之一；(π*_q, π̂) 诱导的带符号子集，或者 (q, π̂) 对，都在并集内。ρ 剖面从预先声明的网格中、在 tuning 种子 900–949 上按 v5 规则选出（argmin geomean N80_pen，0 错误流）。

**为什么不做 heavy/light 链式拆分。** 把 D 拆成高方差段 H 和低方差段 L，各自用小并集，看起来 β 更小。但两段的宽度是相加而不是 ℓ2 合并，损失大于 log 计数的节省。数值示例：H = 3 段，L = 6 段，δ_main 对半分，β_H = 10.05，β_L = 13.4；当 L 占 20% 方差时，宽度为 (4.01 + 2.31)√V = 6.32√V，比 FDC 的 √(2 · 14.22) √V = 5.33√V 还宽；即使 L 只占 5%，也是 5.53√V。而且"重段"由未知的基率决定（CR9 的方差集中在 s = 2、6、8，而不是 w_s 最大的 s = 3），无法做到数据无关。因此没有实现。

### 2.6 定理 FDC-bet-1（检查点 FWER）

在 fdc_theorem §1 的设计与 §2 的概率空间下，取 E = E_main ∩ E_var，其中 E_main 是 (q, π, k) 并集（FDC-bet），或者族 A ∪ 族 B 的并集（FDC-MR），每个事件都用真实 μ 的 Chernoff 阈值 t(μ) 陈述；E_var 是精确超几何（或 L2）盒子的同时覆盖。δ_main + δ_var = 0.045 + 0.005 = δ。在 E 上，对每个 k、q 和任意可行 π̂_q(k)，取挑战者 π′ = π*_q：

  J(π*_q) − J(π̂_q) = Δ̂ + Y ≤ Δ̂ + B(D) ≤ U_q(k)。

所以 U_q(k) ≤ ε 时不会发生错误认证。两种观察窗口（停在 12/15，或运行到 τ_R），以及推论 P(V > 0) ≤ δ、E[V/(R ∨ 1)] ≤ δ，都与 fdc_theorem §5–§6 相同。所用工具全部是已发表的定理（Hoeffding 1963 Thm 4；Bennett 引理；Vatutin–Mikhailov 的 Poisson-二项表示；精确超几何检验反演），加上 Chernoff 不等式和并集界。
